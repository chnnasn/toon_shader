# 可露凯：唯一场景入口

双击同目录的 **ClukayShowcase.unity**。或者使用 Unity 菜单 **Tools → 可露凯 → 打开唯一场景（换装、旋转、法线、枪）**。

这个场景以原换装版为基础，保留三个部位共 27 种搭配、模型原有法线与表情、水平旋转，以及 Summer416 枪模型。之前的嘴周法线与高光修正已撤回。

进入 Play 后，所有功能统一在右侧滚动面板中；可以拖动竖向滚动条，或把鼠标放在面板上使用滚轮上下查看：

- 上衣、下装、腿部换装。
- 模型水平旋转、自动旋转与转速（支持反向）。
- 主灯光方位、俯仰、自动旋转与转速，以及重置视角/灯光。
- 正常、底色、法线、粗糙度/金属度/AO、主光阴影、直接高光、环境反射、间接漫反射、透明遮罩、白模共十种查看模式；使用 PropertyBlock，不覆盖材质资源。白模保留明暗、法线和透明裁切。
- 显示/隐藏枪模型；枪与角色随转台一起旋转。
- 本地搭配保存、读取与恢复默认。

`Weapons/Summer416.prefab` 是枪的入口。所有可露凯资源统一位于 `Assets/Studies/ClukayStudy` 下。

旧的 Showcase、Hybrid、Recovered 和 Assets 内的换装备份场景已按要求直接删除，本次没有创建场景备份。其他角色场景不在此次删除范围。

这是当前重建版本，并非已经百分百还原原版渲染。
