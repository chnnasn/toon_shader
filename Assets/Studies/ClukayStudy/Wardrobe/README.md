# 可露凯部件替换（本地学习）

打开唯一场景 `Assets/Studies/ClukayStudy/Scenes/ClukayShowcase.unity`，进入 Play，使用右侧换装、水平旋转、法线/底色查看和枪显示按钮。原 ClukayWardrobe 场景已迁移并统一命名。
上衣、下装、腿部各三种，共 27 种组合；支持旋转、恢复默认、本机保存/读取。
不修改手机穿戴、不进行购买、不包含新搭建的游戏背景。

## 2026-09-17 装配修正

- `P1/P2/P3_cloth2_lod0` 是各款上衣配套的胸部皮肤网格，不是可关闭的布料。恢复网格并分配皮肤材质。
- 以两套模型共有的 HairB 网格包围盒为参照，PMX 头部世界坐标修正约 `(0, -0.0001011, -0.0712995)` 米。原版身体/头发保持位置不变。
- 原版 hair_lod0 已有 HairA/HairB 两个子网格；移除重复 PMX HairB，分别分配两种材质。
- 补齐 P2 网袜内层皮肤及鞋内脚部、P3 大腿连接皮肤。
- 皮肤、头发材质校准保存于本目录，不覆盖 Recovered 展示版本的材质。

原始 44 个网格及索引见 `Tools/ExtractedGF2/Wardrobe/manifest.json`。
验证与正面、侧面、背面近景见 `Tools/Previews/Wardrobe/`。
27 种组合检查覆盖分组互斥、胸部皮肤启用、材质引用和着色器错误；不等同于每个角度都已像素级验证。
